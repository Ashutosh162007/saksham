# AICTE SAKSHAM

Frontend demonstration of a **Smart Approval, Compliance & Workflow Intelligence** workspace.

This is a fictional, client-side prototype. It is **not** an operational AICTE system. Records, officers, institutions, visits, notifications and audit events are sample data. No emails, SMS messages or inspections are sent or booked.

## Run

```bash
npm install
npm run dev
```

## Stack

React, TypeScript, Vite, Tailwind CSS, React Router, Recharts, Lucide icons.

Demo state persists in `localStorage` under `aicte-saksham-demo-v1`. Use **Administration and Settings** to change the demonstration clock, switch demo roles, or restore seed data.
